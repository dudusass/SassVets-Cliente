# SassVets: cliente do jogo

Servidor de Tibia 8.60 com EXP alta e itens editados. **Fase de testes.**

## Como instalar

1. Baixe o **SassVets-Setup** da versão mais nova em [Releases](https://github.com/dudusass/SassVets-Cliente/releases/latest).
2. Abra o arquivo. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo** (o instalador ainda não tem assinatura digital).
3. Escolha a pasta e conclua. Não precisa de administrador.
4. Abra o **SassVets** pelo atalho da área de trabalho e entre com a sua conta.

O cliente já vem configurado para o servidor (`137.131.238.226`, porta `7171`).

## Desinstalar

Menu Iniciar → SassVets → **Desinstalar SassVets**.
